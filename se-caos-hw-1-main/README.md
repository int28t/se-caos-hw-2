## Описание проекта
Имитационная модель регулируемого перекрестка, реализованная на языке C. Программа использует последовательную событийную имитацию для моделирования движения автомобилей и пешеходов в консольном режиме. 

Проект разработан с фокусом на надежность системного кода и строгую проверку инвариантов предметной области.

## Особенности реализации
* **Строгий контроль инвариантов:** Аппаратный запрет на пересечение конфликтующих направлений, соблюдение переходных интервалов безопасности и контроль вместимости очередей.
* **POSIX-совместимый ввод-вывод:** Чтение конфигурации и запись журналов реализованы напрямую через дескрипторы системными вызовами `read`, `write`, `open` с перехватом прерываний `EINTR`.
* **Управление потоками:** Поддержка фиксированной и адаптивной стратегий светофора, а также честного FIFO-приоритета для экстренного транспорта.
* **Безопасное завершение:** Корректный перехват POSIX-сигналов `SIGINT` и `SIGTERM` через `sigaction` с выводом итоговой статистики перед штатным завершением.

## Сборка и запуск
Сборка осуществляется через CMake с включенными флагами строгой компиляции (`-Wall -Wextra -Wpedantic`) и санитайзерами памяти (ASan, UBSan).

```bash
# Автоматическая сборка и прогон всех тестовых сценариев
./tests/run.sh

# Ручной запуск симуляции
./build/crossroad data/demo.conf results/demo.log
```
